# Acme (demo brand)

A made-up brand so the tests and the example projects have something to build with. Not a real company. Copy
this folder's shape for your own brand (skill `add-brand`, field reference in `brands/README.md`).

- `tokens.json`: colours, type styles with their 1920x1080 and vertical size sets, spacing, radii, shadows.
- `video.yaml`: which token each video role uses, the text/background pairs checked for contrast, logos, captions.
- `DESIGN.md`: the rules in words; sections 2-6 are copied into every motion direction.
- `FONTS.md`, `REVIEW.md`, `logo/`.
