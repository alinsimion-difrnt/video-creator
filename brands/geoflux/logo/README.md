# Logo

The GEOflux.ai wordmark from the geoflux.ai header, as single-colour SVGs (no scripts, no external references, no
raster images; ADR 0019).

- geoflux-primary.svg: orange #FF6600, for light backgrounds (as on the site).
- geoflux-on-dark.svg: white, for dark backgrounds.
- geoflux-mono.svg: navy #1C2B3B.
